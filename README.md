# My React Projects

Welcome to my collection of React projects! This repository contains various mini-projects built using React and Vite. Each project demonstrates different features and functionalities of React.

## Projects

1. **Counter** - A simple counter application.
2. **Tailwind Props** - A project showcasing the use of Tailwind CSS with React.
3. **Background Changer** - An app to change the background color.
4. **Password Generator** - A tool to generate secure passwords.
5. **Currency Converter** - An application to convert currencies.
6. **React Router** - A project demonstrating the use of React Router.
7. **Mini Context API** - A project using React's Context API.
8. **Theme Switcher** - An app to switch between light and dark themes.
9. **Todo Context API** - A todo list application using Context API.
10. **Redux Toolkit Todo** - A todo list application using Redux Toolkit.
11. **Blog** - A full-featured blog application.

## Getting Started

To get started with any of these projects, follow these steps:

1. Clone the repository:
    ```sh
    git clone https://github.com/your-username/my-react-projects.git
    cd my-react-projects
    ```

2. Navigate to the project directory:
    ```sh
    cd project-directory
    ```

3. Install dependencies:
    ```sh
    npm install
    ```

4. Start the development server:
    ```sh
    npm run dev
    ```

## Technologies Used

- **React** - A JavaScript library for building user interfaces.
